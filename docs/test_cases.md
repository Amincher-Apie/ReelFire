### 案例 7：CT/T 类别混淆

| 项目 | 内容 |
|---|---|
| 视频 | test_01.mp4 |

| 实际结果 | ⚠️ 部分帧 CT 被误检为 T，或 T 被误检为 CT |
| 混淆原因 | CT 和 T 角色外观相似（都是人类模型），远距离时特征不明显 |
| 改进方向 | 增加 CT/T 对比训练样本，强化阵营标志特征学习 |

## Valorant 失败案例（3 个）

### 案例 V6：左手持枪视角武器漏检

| 项目 | 内容 |
|---|---|
| 视频 | test_06.mp4 / test_07.mp4 |
| 时间戳 | 左手持枪视角片段 |
| 预期结果 | 检测到武器 |
| 实际结果 | ❌ 左手持枪视角下 weapon 检测失败 |
| 漏检原因 | 训练数据全部为右手持枪视角，模型未学习左手持枪特征 |
| 影响评估 | 不影响精彩片段提取（最终逻辑基于 enemy 出现/消失，不依赖 weapon）|
| 改进方向 | 补充左手持枪截图训练，或增加水平翻转数据增强（fliplr=1.0）|

### 案例 V7：enemy 置信度偏低

| 项目 | 内容 |
|---|---|
| 视频 | test_04/06/07.mp4 |
| 预期结果 | enemy 检测置信度 > 0.7 |
| 实际结果 | ⚠️ enemy 平均置信度 0.551-0.636，低于 weapon 的 0.776-0.870 |
| 偏低原因 | enemy 训练样本仅 32 个标注，且敌人外观差异大（不同角色、距离、角度）|
| 影响评估 | 置信度 0.35 阈值下仍能检测，但高阈值（0.6+）会漏检 |
| 改进方向 | 补充 enemy 标注至 60+ 个，覆盖更多角色和距离 |

### 案例 V8：v1 验证集指标虚高（过拟合）

| 项目 | 内容 |
|---|---|
| 对比版本 | valorant_v1 vs valorant_v2 |
| 预期结果 | 数据量增加后指标应提升 |
| 实际结果 | ⚠️ v1 验证集 mAP50=0.995，v2 反而降至 0.795 |
| 虚高原因 | v1 验证集仅 2 张图 4 个实例，样本过少导致指标失真 |
| 教训 | 小数据集验证指标不可信，需结合实际视频效果评估 |
| 说明 | v2 实际视频检测效果优于 v1（weapon 误检减少、片段更精准）|

## 改进建议

| 优先级 | 改进项 | 游戏适用 | 预期效果 |
|---|---|---|---|
| P0 | 补充手枪标注（+15 个）| CS2 | 手枪检测率提升 50%+ |
| P0 | 补充 enemy 标注（+30 个）| Valorant | enemy 置信度提升至 0.7+ |
| P1 | 增加 CT/T 对比样本 | CS2 | 减少类别混淆 |
| P1 | 补充左手持枪截图 | Valorant | 左手持枪 weapon 检测恢复 |
| P2 | 补充远距离截图 | CS2 | 提升小目标检测率 |
| P2 | 增加水平翻转增强（fliplr=1.0）| Valorant | 缓解左手持枪漏检 |
| P3 | 多尺度训练（imgsz=1280）| 通用 | 提升不同尺寸目标检测能力 |
