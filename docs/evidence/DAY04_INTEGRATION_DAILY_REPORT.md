## 二、完成内容

### 1. 多分支集成与契约统一

- 合并后端 Day 04、Agent 稳定性、CV 高光决策、片段 Schema 和前端功能分支。
- 统一 `report-data`、统计接口、编辑器片段结构和 Agent 逐片段评论的消费方式。
- 保留 CV 证据字段、后端生命周期接口与前端模块化结构，解决多分支同时修改核心文件时的契约差异。
- 补充项目上传持久化、任务权限、片段输入校验和流式报告兼容性覆盖。

### 2. 项目页与导航路径

- 将导航收敛为项目、分析工作台和剪辑工作台三个核心页面，上传和历史能力合并进项目页。
- 项目页支持卡片/列表两种等价视图，两种视图展示一致的信息并补充素材名称。
- 项目列表固定每页 10 项，避免项目数量增长后形成超长页面。
- 增加当前项目会话状态；用户选定项目后，分析与剪辑工作台复用同一项目，退出登录时清除。
- 修复从项目详情返回项目列表无响应及跨页面反复要求选择项目的问题。

### 3. 长视频流式分析

- 建立 60 秒窗口、30 秒错位的双逻辑分块队列，按两队列交替顺序消费，不预先生成短视频文件。
- YOLO 在单个逻辑分块完成后立即产出候选片段；首个有效结果可解锁剪辑工作台，剩余分块在后台继续处理。
- 重叠候选片段按时间并集合并并稳定编号，减少双窗口扫描产生的重复视觉点和重复 Agent 请求。
- 增加候选流水线基准脚本和本地服务启动脚本，便于长视频首批时延与整片耗时评估。
- 将任务阶段、已扫描分块、已发现候选、追踪和 Agent 状态持续同步到前端，降低长时间无反馈造成的等待感。

### 4. YOLO、候选评分与目标追踪

- 新增候选选择器，把检测结果、活动强度和片段证据整理为统一候选结构。
- 接入目标追踪，并调整为每个逻辑分块内独立完成 YOLO 与追踪，不在全片 YOLO 结束后再次串行回扫。
- 将追踪摘要纳入高光评分和统计，改善单帧误检、重复目标计数和跨帧事件连续性判断。
- 保留分块边界裁剪与跨窗口时间合并，避免追踪状态跨不连续窗口污染。

### 5. Agent 与知识检索

- 将 Agent 调用改为按已合并片段逐项异步执行；每个片段完成后即可单独写入并推送评论。
- 增强 Dify 网络日志、错误分类、有限重试和脱敏请求标识，区分认证、限流、超时、网络、服务端与契约错误。
- 支持 Ollama 及 OpenAI-compatible Embedding 配置；知识检索不可用时降级为空证据，不阻塞 YOLO、剪辑工作台或逐片段 Agent 主链路。
- 前端区分等待、执行、降级和失败状态，避免长期停留在“正在检查 Agent 调用状态”而缺少可诊断信息。

### 6. 分析工作台

- 候选片段和关键帧默认每页 5 项，可由用户调整且支持显示全部，避免长视频一次渲染全部数据。
- 关联片段卡片改为可交互选择；单片段审核模式会同步展示该片段关键帧。
- 增加“全部关键帧审核”独立模式，使全量审核不再受当前片段选择影响。
- 修正图表数据映射、空状态与尺寸布局，使数据可视化对应当前任务真实结果。

### 7. 剪辑工作台

- 统一视频预览、片段审核、选中片段证据和分析统计的卡片层级；分析统计跨两列展示，减少页面中心空白。
- 精彩片段列表默认每页 5 项，并将证据从重复列表项中抽离为当前选中片段详情。
- 修复时间轴播放头、视频进度与精彩片段指示器的左右边界对齐。
- 列表选择、时间轴点击和播放进度改为弱绑定：仅在用户操作发生时同步一次，播放过程不再周期性抢回列表选中项。
- 增加当前片段单独导出，并在打开导出中心时自动预选该片段。
- 增加键盘操作：`Space` 播放/暂停，`←`/`→` 与小键盘 `4`/`6` 逐帧，`↑`/`↓` 与小键盘 `8`/`2` 跳转前后精彩片段；首尾钳制且输入控件不会误触发。

## 四、问题与处理

1. 长视频需要等待全片 YOLO 结束才能进入剪辑。
   - 调整为双窗口逻辑分块交替消费，首批结果先开放工作台，后续持续追加。
2. 双窗口扫描产生大量相同或重叠精彩片段。
   - 在每轮分块结果进入前端和 Agent 前按时间并集归并，统一编号并去重。
3. 目标追踪在全片检测后串行执行，破坏流式链路。
   - 将追踪下沉到单分块处理过程，分块结果一次完成检测、追踪、评分和发布。
4. Embedding 或 Agent 网络异常会让页面长期等待。
   - 检索失败降级但不阻塞主链路；Agent 增加逐片段状态、结构化错误与网络日志。
5. 长视频片段和关键帧全量渲染导致页面过长。
   - 项目固定 10 项分页，分析和剪辑数据默认 5 项分页并支持用户调整。
6. 播放进度持续重置用户手动选择。
   - 改为事件驱动的一次性同步，取消播放过程中的强制选中。
