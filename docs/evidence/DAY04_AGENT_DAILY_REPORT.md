## 四、遇到的问题

1. 问题：Dify 的 401、网络错误、限流和模型输出错误此前统一显示为调用失败。
   - 原因：适配器只有一次阻塞请求，异常没有结构化分类。
   - 解决方法：增加有限指数退避和提供方错误码；认证、请求和契约错误不盲目重试。

2. 问题：全仓测试无法全部通过。
   - 原因：当前 Windows 应用控制策略阻止加载 `torch_python.dll`，影响 CV 引擎
     导入和一个依赖 CV 的损坏视频用例。
   - 解决方法：Agent 专项 81 项全部通过，并在验收记录中保留 214 项全仓测试的
     212 通过、2 项环境阻塞证据；不把环境阻塞伪装成全绿。

3. 问题：Dify 画布能显示 JSON，但首次 API 业务调用解析失败。
   - 原因：DeepSeek 的阻塞 API 在业务 JSON 前返回 `<think>...</think>`，画布会
     单独折叠展示，而仓库解析器此前把整段当作 JSON。
   - 解决方法：适配器只剥离开头闭合的推理块，再按原契约解析 JSON；新增回归
     测试后重新实调，最终保留 `provider.type=dify` 且没有模型生成错误。
